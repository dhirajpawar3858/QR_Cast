🔳 Offline QR File Transfer

100% offline · no server · no internet

Move a file between two devices using only the screen & a camera

The sender compresses, encrypts, and displays your file as a rapid animated QR sequence. The receiver scans it with a camera, reassembles, decrypts, and saves the file — all in the browser, with no network access at any point.

📤

Sender

Upload a file, set a passphrase, tune the QR density/FPS, and broadcast the animated QR.
📥

Receiver

Open the camera, scan the frames until complete, enter the passphrase, and save the file.

How it works

  1. File bytes → gzip → AES-GCM encrypt (key from your passphrase via PBKDF2).
  2. Ciphertext is split into fixed-size chunks; each becomes one QR frame (raw binary byte mode).
  3. A repeating header frame carries the manifest (filename, chunk count, salt, IV, SHA-256).
  4. The sender loops the frames; the receiver collects missing indices until all are captured.
  5. The receiver verifies SHA-256, decrypts, decompresses, and downloads the original file.

Same passphrase on both sides. Share it out of band (in person, etc.) — it is never transmitted.
